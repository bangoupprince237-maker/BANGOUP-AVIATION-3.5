Version 29 — 07/11 : ACCÈS PRIVÉ PAR CODE
====================================================
- Le code est demandé À CHAQUE ouverture du jeu (rien n'est mémorisé sur l'appareil).
- Code de départ : celui donné par Claude dans la conversation.
- Pour changer le code : dans le jeu, bouton « 🔑 Code d'accès » (en haut à droite),
  avec votre CODE MAÎTRE (gardez-le pour vous, il n'est écrit dans aucun fichier).
- Pour que le nouveau code reste après un redémarrage du serveur : ajoutez dans
  Render > Environment la variable RENDER_API_KEY (votre clé API Render).

Version 5 — 05/11
====================================================
Version 2 (Lot 2) — 31/10

CONTENU DU DOSSIER
  public/index.html      -> TOUT le jeu (un seul fichier)
  server.js              -> le serveur (site + multijoueur)
  package.json           -> la liste des outils pour Render
  demarrer-windows.bat   -> pour tester sur votre PC
  LISEZ-MOI.txt          -> ce fichier

METTRE EN LIGNE (GitHub + Render)
  1. GitHub : envoyez TOUT le contenu de ce dossier dans votre dépôt
     (Add file -> Upload files -> glissez les fichiers et le dossier public -> Commit changes).
  2. Render : New + -> Web Service -> choisissez votre dépôt GitHub.
       Build Command : npm install
       Start Command : node server.js
     Cliquez Create Web Service. Attendez 2-3 minutes.
  3. Ouvrez l'adresse donnée par Render (https://....onrender.com).

METTRE À JOUR (les fois suivantes)
  Remplacez seulement public/index.html sur GitHub. Render redémarre tout seul.

TESTER SUR VOTRE PC (facultatif)
  Installez Node.js (nodejs.org, version LTS), puis double-cliquez demarrer-windows.bat.
  Le jeu s'ouvre sur http://localhost:3000

JOUER À PLUSIEURS
  Ouvrez l'adresse du site sur 2 onglets ou 2 ordinateurs, mettez le MÊME nom de salon,
  puis cliquez « Multijoueur ». Le nombre de joueurs s'affiche en haut à droite.

TOUCHES PRINCIPALES
  Z / S : gaz +/-        Flèches : piloter (↓ = cabrer)     Q / D : direction
  F / V : volets +/-     G : train      B : freins      P : frein de parc
  W : aérofreins         Tab : caméra   C : vue dégagée   H : panneau   R : recommencer
